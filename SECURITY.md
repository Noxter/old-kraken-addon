# Політика безпеки (Security Policy)

## Підтримувані версії

Ми підтримуємо та випускаємо оновлення безпеки для таких версій аддона:

| Версія | Підтримка | Примітки |
|---|---|---|
| `0.5.x` (`main`) | :white_check_mark: | Поточний стабільний реліз |
| `alpha` | :white_check_mark: | Гілка активної розробки |
| `< 0.5.0` | :x: | Застарілі версії |

## Повідомлення про вразливості

Якщо ви виявили потенційну вразливість у безпеці аддона (зокрема у валідації мережевих повідомлень гільдійного транспорту, обробці даних чи збереженні налаштувань):

1. **Будь ласка, НЕ створюйте публічні Issues.** Публічне розкриття може нашкодити гравцям гільдії до виходу виправлення.
2. Скористайтеся функцією **Private Vulnerability Reporting** на вкладці [Security](../../security/advisories/new) нашого репозиторію на GitHub (після її активації) або зв'яжіться з автором приватно.
3. Опишіть проблему, кроки для відтворення та потенційний вплив.

Ми намагаємося переглядати приватні звернення якомога швидше, підготувати виправлення та опублікувати реліз перед публічним розкриттям деталей. Дякуємо за допомогу в захисті спільноти!
