# Old Kraken Guild Addon

Україномовний аддон для керування гільдійними даними та активностями у WoW Forever.

## Статус

Версія `0.3.0`. Модуль Guild Roster отримав пошук, фільтри, сортування та кольори класів. Зміни потребують тестування безпосередньо в клієнті WoW Forever.

## Цілі MVP

- **Guild Roster** — перегляд і робота з гільдійним ростером.
- **Group Finder** — пошук гравців для груп.
- **Events / Calendar** — планування гільдійних подій.
- **WoW Hub** — додаткове джерело для імпорту або звірки даних ростера.

## Перевірено в WoW Forever 1.60.1 (70938)

У клієнті підтверджено:

- `GetBuildInfo()` повертає interface number `16001`.
- `C_GuildInfo.GuildRoster()`, `GetGuildRosterInfo()` та `GetNumGuildMembers()` доступні.
- `GUILD_ROSTER_UPDATE` спрацьовує після запиту оновлення ростера.
- `C_Calendar` та `C_Calendar.GetEventInfo` доступні.
- `C_ChatInfo.SendAddonMessage` доступна, але `AreOutgoingAddonChatMessagesRestricted()` повертає `true` у перевіреному клієнті.

Наявність функцій не гарантує доступність усіх операцій. Календар і обмін аддон-повідомленнями потребують окремих функціональних тестів.

## Guild Roster v0.3.0

- Пошук за ім'ям персонажа.
- Перемикання фільтра статусу: усі / онлайн / офлайн.
- Перемикання фільтра класу.
- Сортування кліком по заголовках: ім'я, ранг, рівень, клас.
- Онлайн-учасники завжди відображаються першими.
- Сортування за замовчуванням: рівень за зростанням усередині групи онлайн/офлайн.
- Імена та назви класів використовують кольори класів WoW, якщо вони доступні в клієнті.
- Лічильник показує повний склад, кількість онлайн і кількість записів після фільтрації.
- Пошук, фільтри й сортування зберігаються через SavedVariables.

## Джерела даних

- Ігровий гільдійний ростер є основним джерелом актуального складу, рівнів і рангів.
- WoW Hub розглядається як допоміжне джерело. Спосіб отримання та формат імпорту ще потрібно дослідити.

## Архітектура та обмеження

- Самостійний аддон на Lua/XML.
- Початковий етап — без власного backend-сервера.
- Для локальних даних використовується механізм WoW SavedVariables.
- Можливість обміну подіями та даними між клієнтами через канали WoW Forever потрібно окремо перевірити.
- Зовнішні HTTP-запити з аддону не вважаються доступними без підтвердження API клієнта.

## Використання

- `/okr` або `/oldkraken` — відкрити вікно ростера.
- Кнопка **Оновити** — запросити оновлення ростера.
- Поле пошуку — фільтрувати за ім'ям.
- Кнопка **Статус** — перемикати усі / онлайн / офлайн.
- Кнопка **Клас** — циклічно перемикати клас.
- Клік по заголовках **Ім'я**, **Ранг**, **Рів.**, **Клас** — змінювати сортування.
- `/okr refresh` — запросити оновлення без відкриття вікна.
