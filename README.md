# Old Kraken — Guild Management Addon

[![WoW Forever](https://img.shields.io/badge/WoW_Forever-1.60.1-blue.svg)](https://github.com/Noxter/old-kraken-addon)
[![Interface](https://img.shields.io/badge/Interface-16001-orange.svg)](https://github.com/Noxter/old-kraken-addon)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/Tests-60%20test%20files-brightgreen.svg)](tests/)

**Old Kraken** — аддон для гри World of Warcraft (клієнт **WoW Forever 1.60.1**, Interface `16001`), створений для об'єднання ключових активностей гільдії в одному зручному інтерфейсі: реєстр учасників, гільдійний пошук груп, календар подій, розумні сповіщення та майстерня професій.

Аддон розроблено виключно на чистому **Lua** (без XML та сторонніх бібліотек на зразок LibStub чи Ace3). Весь обмін даними здійснюється через внутрішньоігровий канал гільдії без використання зовнішніх серверів чи баз даних.

---

## Мови інтерфейсу

Аддон повністю підтримує дві мови:
- **Українська** (за замовчуванням)
- **English**

Змінити мову можна у вікні аддона: **Налаштування** (`/okr`) → вибір мови → **Застосувати й перезавантажити**.

## Можливості

### 1. Гільдійний ростер (Guild Roster)
- Швидкий перегляд складу гільдії з відображенням рівнів, класів, спеціалізацій, рангів, зон і тривалості офлайну.
- Показ іконки спеціалізації біля назви класу та назви спеціалізації в тултипі класу (за відсутності достовірних даних спеціалізація не підставляється).
- Пошук персонажів за ім'ям у реальному часі.
- Фільтри за статусом: *Усі*, *Онлайн*, *Офлайн*.
- Фільтр за класами з підтримкою кольорів класів WoW.
- Сесійний фільтр учасників, у яких встановлено аддон Old Kraken.
- Сортування кліком по заголовках колонок: *Ім'я*, *Ранг*, *Рівень*, *Клас*, *Локація* (включно з давністю офлайну для офлайн-учасників, без урахування регістру). Онлайн-гравці завжди відображаються першими.
- Збереження параметрів пошуку, фільтрів та сортування в `SavedVariables`.

### 2. Пошук гільдійних груп (Guild Group Finder)
- Створення оголошень для підземель, рейдів та довільних активностей із локалізованим відображенням стандартних авто-назв.
- Приховування оголошень, автор яких підтверджено офлайн, та автозакриття власного неактивного набору.
- Подання заявок із вибором бажаної ролі (Танк, Лікар, DPS).
- Керування заявками, підтвердження учасників та резервування місць у групі.
- Автоматична синхронізація фактичного складу групи/рейду автора.
- Кнопки швидкого запрошення до групи через нативні ігрові функції.
- *Відокремлений від вбудованого в гру LFG — працює виключно всередині вашої гільдії.*

### 3. Календар гільдійних подій (Guild Events)
- Планування рейдів, підземель, PvP та зборів гільдії.
- Налаштування опису, дати, точного часу (з відображенням за місцевим часом гравця) та ліміту місць.
- Запис учасників із зазначенням ролі.
- Прийняття та відхилення заявок лідером події, керування резервом.
- *Окремий календар аддона — не створює подій у вбудованому календарі клієнта.*

### 4. Розумні сповіщення (Smart Notifications)
- Спливаючі банери та звукові сповіщення про нові групи, події, заявки та замовлення.
- Можливість керування сповіщеннями за модулями, тестування банерів і скидання позицій у вкладці **Налаштування** (а також перетягування на екрані через `/okr alerts ...`).
- **Режим тиші в інстансах:** фонові сповіщення автоматично приглушуються під час перебування в підземеллях і рейдах.
- **Відкладення в бою:** банери приховуються під час бою, щоб не заважати огляду; заявки до власних груп агрегуються й показуються після виходу з бою. Коли банер для рішень, подій чи майстерні прихований у бою чи інстансі, текстовий лог дублюється в чат.

### 5. Майстерня професій та замовлень (Workshop) — *У розробці (Experimental)*
- Каталог вивчених професій та рецептів майстрів гільдії.
- Пошук майстрів, які володіють потрібним рецептом.
- Система замовлень на крафт: замовник описує потрібний предмет і винагороду, а майстри пропонують виконання.
- Відстеження передачі матеріалів, предметів і оплати через ігровий обмін та пошту.
- *Модуль перебуває в статусі In Development / Experimental: окремі сценарії та автоматичний облік передач у грі потребують додаткової перевірки на двох живих клієнтах. Детальний технічний опис дивіться у [docs/WORKSHOP.md](docs/WORKSHOP.md).*

## Встановлення

1. Перейдіть до розділу [Releases](https://github.com/Noxter/old-kraken-addon/releases) і завантажте архів **`OldKraken.zip`** останнього релізу.
2. Розпакуйте архів у папку аддонів гри:
   ```text
   World of Warcraft/Interface/AddOns/
   ```
   *(Переконайтеся, що шлях виглядає як `Interface/AddOns/OldKraken/OldKraken.toc`).*
3. Перезапустіть гру або введіть у чаті `/reload`.

## Команди (Slash Commands)

| Команда | Дія |
|---|---|
| `/okr` або `/oldkraken` | Відкрити головне вікно аддона (Ростер) |
| `/okr group` | Відкрити Пошук груп (Group Finder) |
| `/okr events` або `/okr calendar` | Відкрити Календар подій |
| `/okr workshop` | Відкрити Майстерню |
| `/okr orders` | Перейти безпосередньо до вкладки замовлень |
| `/okr recipes` | Перейти безпосередньо до пошуку рецептів |
| `/okr alerts group` | Показати тестовий банер групи для налаштування його позиції |
| `/okr alerts request` | Показати тестовий банер заявки для налаштування позиції |
| `/okr alerts event` | Показати тестовий банер події для налаштування позиції |
| `/okr alerts workshop` | Показати тестовий банер замовлення для налаштування позиції |
| `/okr comm status` | Вивести діагностику гільдійного транспорту повідомлень |
| `/okr comm test` | Надіслати тестовий пінг у гільдійний канал |

Кнопка біля мінікарти відкриває Ростер (лівий клік) або Пошук груп (правий клік). Позицію кнопки можна перетягувати по колу мінікарти.

## Комунікація та збереження даних

- **Канал обміну:** усі повідомлення передаються через нативний гільдійний канал (`GUILD`) із префіксом `OLDKRKN`. Зовнішні сервери не використовуються.
- **Збереження даних:** персональні налаштування та кеш зберігаються у файлі `WTF/Account/<Акаунт>/SavedVariables/OldKraken.lua` (`OldKrakenDB`, поточна схема версії 3).
- **Синхронізація:** обмін даними між учасниками вимагає наявності встановленого аддона в обох сторін та одночасного перебування в мережі (або через механізм 1-hop ретрансляції збережених станів).
- Повний технічний опис транспортного протоколу наведено в [docs/COMMUNICATION.md](docs/COMMUNICATION.md).

## Версія збірки

У **Alpha ZIP**, створених GitHub Actions (`scripts/stamp-version.py`), до базової версії з `OldKraken.toc` додається `+g` і перші 12 символів Git-коміту, тоді як релізні збірки використовують чисту версію без Git-суфікса:
- **Alpha ZIP:** `<version>+g<12-символьний SHA>` (наприклад, `0.5.6-alpha.1+g0123456789ab`)
- **Release ZIP та сирий `OldKraken.toc` релізу:** базова версія без суфікса (наприклад, `0.5.5`)

Цю версію видно в списку аддонів і ростері; різні Git-збірки одного релізу позначаються окремо.

## Тестування та надійність

Проєкт містить **60 автоматизованих тестових файлів** (`tests/test_*.py`), які CI (`.github/workflows/validate-pr.yml`) запускає через Python/Lupa на середовищі Lua 5.1. Вони перевіряють:
- Цілісність бази даних та міграції схеми (`Database.lua`).
- Кодек, чергу, фрагментацію та обробку пакетів (`Communication.lua`).
- Моделі станів груп, monotonic fence та дедуплікацію (`GroupFinder.lua`).
- Життєвий цикл замовлень та безпеку прав автора (`GuildEvents.lua`, `WorkshopOrders.lua`).

> *Автоматизовані тести підтверджують коректність бізнес-логіки та протоколу. Реальна доставка повідомлень у грі залежить від доступності чат-API клієнта та наявності гравців онлайн.*

## Структура кодової бази

Файли завантажуються строго в порядку, визначеному в `OldKraken.toc`:

```
OldKraken/
├── Database.lua                 # Схема даних та міграції SavedVariables (OldKrakenDB)
├── Locale.lua                   # Таблиці локалізації (Українська та English)
├── Core.lua                     # Життєвий цикл, шина подій та спільний стиль UIStyle
├── UIHub.lua                    # Головне спільне вікно та менеджер сторінок
├── Communication.lua            # Транспорт повідомлень (GF2 протокол у каналі GUILD)
├── GuildRoster.lua              # Інтерфейс та логіка гільдійного ростера
├── ActivityCatalog.lua          # Довідник підземель, рейдів, рекомендованих рівнів та іконок
├── GroupFinder.lua              # Модель гільдійного пошуку груп та валідація станів
├── GroupFinderIntegration.lua   # Синхронізація зі складом поточної ігрової паті/рейду
├── GroupFinderChat.lua          # Форматування та клікабельні посилання оголошень у /g
├── GroupFinderUI.lua            # Інтерфейс карток та деталей Group Finder
├── GroupFinderAPI.lua           # Безпечна read-only діагностика нативного C_LFGList
├── GuildEvents.lua              # Календар подій гільдії та облік заявок
├── Workshop.lua                 # Каталог професій персонажів гільдії
├── WorkshopRecipes.lua          # Сканування та локальний кеш рецептів
├── WorkshopSync.lua             # Пакетна синхронізація великих знімків рецептів
├── WorkshopOrders.lua           # Створення замовлень та керування їхнім статусом
├── WorkshopDeliveries.lua       # Відстеження передач через ігровий обмін та пошту
├── Minimap.lua                  # Кнопка швидкого доступу біля мінікарти
├── ChatLayoutSwitcher.lua       # Перемикач розкладки чату (Ctrl+L: QWERTY ↔ ЙЦУКЕН)
└── Media/                       # Графічні ресурси (герби, іконки ролей, фони)
```

Додаткова технічна документація:
- [docs/WORKSHOP.md](docs/WORKSHOP.md) — внутрішня архітектура Майстерні.
- [docs/COMMUNICATION.md](docs/COMMUNICATION.md) — деталі протоколу обміну повідомленнями.
- [docs/NATIVE_LFG_API.md](docs/NATIVE_LFG_API.md) — дослідження нативного API `C_LFGList` у WoW Forever.
- [docs/EVENTS_EXTERNAL_STORAGE.md](docs/EVENTS_EXTERNAL_STORAGE.md) — концепція зовнішнього сховища подій.
